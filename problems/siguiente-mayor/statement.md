# Siguiente mayor

Para cada posición $i$, el **siguiente estrictamente mayor** a la derecha: el valor $a_j$ del mínimo $j>i$ con $a_j>a_i$ (no el índice).
Si no existe, $-1$. Stack $O(n)$.

## Entrada

$n$ ($1 \le n \le 2 \cdot 10^5$).

$n$ enteros $a_i$ ($-10^9 \le a_i \le 10^9$).

## Salida

$n$ enteros.
