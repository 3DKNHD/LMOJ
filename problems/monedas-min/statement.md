# Mínimas monedas

$n$ tipos de moneda, **ilimitadas**. ¿Mínimo número de monedas para sumar exactamente $S$?
Si no se puede, $-1$. DP hacia **adelante** (unbounded). $n \le 100$, $S \le 10^5$.

## Entrada

$n$ $S$ ($1 \le n \le 100$, $1 \le S \le 10^5$).

$n$ enteros $c_i$ ($1 \le c_i \le 10^5$).

## Salida

Un entero.
